# 📚 Academic & Technical References

This project (**X-Ray AI Engine: Bone Fracture Detection using Deep Learning & Explainable AI**) is built upon established research in medical image processing, computer vision, deep transfer learning, and clinical explainability.

---

## 1. 🏥 Clinical Datasets & Public Benchmarks

1. **MURA (Musculoskeletal Radiographs)**
   - *Authors:* Pranav Rajpurkar, Jeremy Irvin, Aarti Bagul, Daisy Ding, Tony Duan, Hershel Mehta, Brandon Yang, Kaylie Zhu, Dillon Laird, Robyn L. Ball, Curtis Langlotz, Katie Shpanskaya, Matthew P. Lungren, Andrew Y. Ng.
   - *Paper:* "MURA: Large Dataset for Abnormality Detection in Musculoskeletal Radiographs"
   - *Publication:* Stanford Machine Learning Group / arXiv:1712.06957 (2017).
   - *Link:* [https://stanfordmlgroup.github.io/competitions/mura/](https://stanfordmlgroup.github.io/competitions/mura/)

2. **FracAtlas: Multi-Region Bone Fracture Dataset**
   - *Authors:* Iftekhar, M. S., et al.
   - *Paper:* "FracAtlas: A Dataset for Bone Fracture Classification, Localization and Segmentation"
   - *Publication:* Nature Scientific Data, 10, 521 (2023).
   - *DOI:* [10.1038/s41597-023-02432-4](https://doi.org/10.1038/s41597-023-02432-4)

3. **GRAZPEDWRI-DX (Pediatric Wrist Trauma Dataset)**
   - *Authors:* Nagy, E., et al.
   - *Paper:* "GRAZPEDWRI-DX: A dataset of pediatric wrist trauma X-rays for object detection and fracture classification"
   - *Publication:* Nature Scientific Data, 9, 395 (2022).
   - *DOI:* [10.1038/s41597-022-01528-6](https://doi.org/10.1038/s41597-022-01528-6)

4. **Kaggle Bone Fracture Detection Datasets**
   - *Multi-Region Bone Fracture Dataset:* [Kaggle Dataset Link](https://www.kaggle.com/datasets/bmadushanirodrigo/fracture-multi-region-x-ray-data)
   - *Bone Fracture Detection using X-Rays:* [Kaggle Dataset Link](https://www.kaggle.com/datasets/vuppalaadithyasairam/bone-fracture-detection-using-xrays)

## 4. 🔬 Radiographic Image Processing (CLAHE)

   - *Author:* Karel Zuiderveld.
   - *Chapter:* "Contrast Limited Adaptive Histogram Equalization"

## 5. 🛠️ Frameworks & Open-Source Libraries

- **PyTorch & Torchvision**: Paszke et al., "PyTorch: An Imperative Style, High-Performance Deep Learning Library" (NeurIPS 2019).
- **Streamlit**: Open-source app framework for Machine Learning and Data Science teams.
- **OpenCV (Open Source Computer Vision Library)**: Bradski, G. (2000). Dr. Dobb's Journal of Software Tools.
- **Scikit-Learn**: Pedregosa et al., "Scikit-learn: Machine Learning in Python" (JMLR 2011).
- **FastAPI**: Modern, fast web framework for building APIs with Python 3.8+ based on standard Python type hints.
- **Plotly**: Python Open Source Graphing Library for interactive medical charts.
